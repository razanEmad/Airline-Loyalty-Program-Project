# ✈️ Airline Loyalty Program Analysis

## 📌 Overview
This project, completed during our internship at the **National Telecommunication Institute (NTI)**, focuses on analyzing an airline loyalty program dataset. The goal was to uncover actionable insights into frequent flyer member behavior, flight activity, and loyalty trends.

By analyzing member demographics, flight history, loyalty tiers, and spending habits, we generated data-driven recommendations to help the airline optimize marketing strategies and refine loyalty incentives.

## 🎯 Key Findings & Insights

### **1. Age Trends**
Identified distinct travel behaviors across different age groups, enabling more precise, targeted marketing strategies.

### **2. Geographic Insights**
Highlighted regions with higher traveler activity—revealing potential opportunities for route expansion or location-based campaigns.

### **3. Points & Engagement**
Found a clear correlation between age and total points earned, suggesting that age-specific promotions can significantly boost loyalty program engagement.

### **4. Flight Frequency & Seasonality**
Detected seasonal flight patterns and typical intervals between flights. These insights can help the airline optimize the timing and structure of loyalty incentives.

## 💾 Dataset Description

Each record in the dataset represents an individual loyalty program member.

| Attribute           | Description |
|---------------------|-------------|
| **Member ID**       | Unique identifier for each frequent flyer member. |
| **FFP Date**        | Date the member joined the Frequent Flyer Program. |
| **First Flight Date** | Date of the member’s first flight. |
| **Age, Gender**     | Member demographic information. |
| **Flight Count**    | Total number of flights taken. |
| **Total Distance**  | Total kilometers flown. |
| **Points**          | Accumulated reward points. |
| **Yearly Spend**    | Spending for two specific years. |

---

## 🧹 Data Cleaning & Preprocessing

Data preparation was performed using **Python** and **Power Query**, including:

- Handling missing values (e.g., filling missing ages with the mean)
- Identifying and removing duplicate records
- Renaming unclear or inconsistent column names
- Correcting data types for accurate calculations and visualization
